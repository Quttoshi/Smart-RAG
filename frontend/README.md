# Smart RAG Frontend

React + TypeScript + Vite chatbot UI for the Smart RAG FastAPI backend.

## Local Development

```bash
npm install
npm run dev
```

The app defaults to:

```env
VITE_API_BASE_URL=http://localhost:8000
```

Create a `.env` file if your backend runs somewhere else.

## Scripts

```bash
npm run dev
npm run build
npm run preview
```
